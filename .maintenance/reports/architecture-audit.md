## 5. GitHub Actions Workflows

### `.github/workflows/vercel-deploy.yml` (Production)

**Triggers:**
- Push to `main` touching: `apps/web/**`, `content/**`, `scripts/sync-content.mjs`, `vercel.json`, workflow file
- Pull requests to `main` (same paths)
- Manual `workflow_dispatch`

**Jobs:**
1. **quality-gate** — Checkout → Setup Node → `sync-content.mjs` → Verify generated content committed → `npm ci` → `npm run build`
2. **deploy-preview** (PR only) — Needs quality-gate → Vercel preview deploy → Comment PR with URL
3. **deploy-production** (main push or dispatch) — Needs quality-gate → Vercel production deploy

**Permissions:** `contents: read`, `pull-requests: write` (minimal)

**Concurrency:** `vercel-${{ github.workflow }}-${{ github.ref }}`, `cancel-in-progress: false` (queued runs)

### `.github/workflows/main.yml` (Remote Only — Pac-Man)

**Triggers:**
- Schedule: Daily at midnight (`0 */24 * * *`)
- Push to `main`
- Manual `workflow_dispatch`

**Job:** `generate` — Uses `abozanona/pacman-contribution-graph@main` → Pushes SVG to `output` branch via `crazy-max/ghaction-github-pages@v2.1.3`

**Permissions:** `contents: write`

**Concerns:**
- Runs on every push to main (in addition to schedule)
- Writes to `output` branch (may conflict with GitHub Pages if used)
- Third-party actions with broad permissions
- Last run failed (2026-08-20)
